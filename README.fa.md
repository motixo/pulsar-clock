# ساعت سفارشی COSMIC

تنظیمات بیشتر برای ساعت COSMIC: متن بولد، نمایش ثانیه، قالب ۱۲ و ۲۴ ساعته، جداکنندهٔ دلخواه تاریخ و ساعت و رنگ متن با کد HEX.

![نمونهٔ تنظیمات ساعت در COSMIC](assets/screenshot.png)

[English](README.md)

این پچ یک اپلت جدا در پوشهٔ کاربر نصب می‌کند تا تنظیمات ساعت با آپدیت بسته‌های سیستم حفظ شوند.

## نصب

روی Arch Linux با `cosmic-applets` نسخهٔ 1.9.0 آزمایش شده است. پچ بر پایهٔ انتشار رسمی `epoch-1.9.0` است.

ابزارهای ساخت را نصب کن:

```sh
sudo pacman -S --needed git rust base-devel
```

سپس با حساب معمولی کاربرت و بدون `sudo` اجرا کن:

```sh
git clone https://github.com/motixo/cosmic-clock.git
cd cosmic-clock
./install.sh
```

اسکریپت نسخهٔ نصب‌شده در Arch را تشخیص می‌دهد، سورس همان انتشار را می‌گیرد، پچ و تست‌ها را بررسی می‌کند و اپلت را می‌سازد. در نصب اول، تنظیمات ساعت اصلی کپی می‌شوند و ساعت سفارشی جای آن را در پنل می‌گیرد.

روی ساعت کلیک کن و **Clock preferences…** را باز کن. اگر پنل از قبل ساعت نداشته، **Custom Clock** را از تنظیمات اپلت‌های پنل اضافه کن.

در توزیع‌های دیگر باید ابزارهای ساخت و کتابخانه‌های توسعهٔ لازم برای همان نسخهٔ COSMIC نصب باشند و نسخه را دستی مشخص کنی:

```sh
./install.sh --ref epoch-1.9.0
```

توزیع‌ها و نسخه‌های دیگر هنوز اینجا آزمایش نشده‌اند. برای دریافت سورس و وابستگی‌های Rust اینترنت لازم است. جزئیات پیش‌نیازها در [راهنمای انگلیسی](README.md#install) آمده است.

## تنظیمات

- **Bold clock text**: بولد شدن ساعت و تاریخ در پنل.
- **Show seconds**: نمایش و به‌روزرسانی ثانیه.
- **24-hour time**: روشن برای قالب ۲۴ ساعته و خاموش برای ۱۲ ساعته.
- **Custom date/time separator**: جداکنندهٔ دلخواه، همراه فاصله‌ها و کاراکترهای Unicode.
- **Custom text color**: رنگ متن با کدهایی مثل `#FF9500` یا `#0AF`، با یا بدون `#`.

تغییرات بلافاصله اعمال و ذخیره می‌شوند. کد رنگ ناقص یا نامعتبر، آخرین رنگ معتبر را نگه می‌دارد. خاموش کردن رنگ دلخواه، رنگ تم را برمی‌گرداند.

جداکننده برای پنل افقی است. بولد و رنگ دلخواه در پنل عمودی هم اعمال می‌شوند.

اگر قبلاً قالب `format_strftime` تنظیم کرده‌ای، گزینهٔ **Use normal date/time formatting** در تنظیمات ساعت آن را پاک می‌کند تا کنترل‌های معمول قالب اثر کنند.

## آپدیت

```sh
git pull --ff-only
./install.sh
```

تنظیمات قبلی حفظ می‌شوند. اسکریپت پردازهٔ ساعت در حال اجرا را نمی‌بندد؛ فایل اجرایی جدید در ورود بعدی یا بارگذاری دوبارهٔ پنل اجرا می‌شود.

اگر در نسخه‌های آیندهٔ COSMIC کد یا API پنل تغییر ناسازگار داشته باشد، ممکن است پچ به تطبیق نیاز پیدا کند. شکست بررسی پچ یا ساخت، فایل اجرایی نصب‌شده را تغییر نمی‌دهد.

برای ساخت بدون نصب یا نصب بدون تغییر اپلت‌های پنل:

```sh
./install.sh --ref epoch-1.9.0 --build-only
./install.sh --ref epoch-1.9.0 --no-activate
```

## حذف

```sh
./uninstall.sh
```

ساعت اصلی به پنل برمی‌گردد و فایل اجرایی و ورودی دسکتاپ سفارشی پاک می‌شوند. تنظیمات و کش ساخت برای نصب دوباره باقی می‌مانند.

برای پاک کردن تنظیمات و کش ساخت هم اجرا کن:

```sh
./uninstall.sh --purge
```

پشتیبان تنظیمات پنل در `~/.local/state/cosmic-clock-custom/backups/` حفظ می‌شود. اگر پنل در حال اجرا نباشد، ساعت اصلی در ورود بعدی استفاده می‌شود.

برای برگشت موقت به ساعت اصلی، بدون حذف اپلت:

```sh
python3 scripts/clock-control.py restore
```

برای فعال‌سازی دوباره:

```sh
python3 scripts/clock-control.py activate
```

## تست‌ها و مجوز

```sh
python3 -m unittest discover -s tests -v
bash -n install.sh uninstall.sh
```

تست‌های نصب و حذف در پوشه‌های موقت اجرا می‌شوند و دسکتاپ را تغییر نمی‌دهند. تست‌های ساعت هم پیش از ساخت، توسط اسکریپت نصب اجرا می‌شوند.
